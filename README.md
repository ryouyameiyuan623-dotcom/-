# -WOLF ROOM（オンライン人狼・試作版）
できること
ルーム作成・6桁コードで参加
1ルーム最大16人
役職人数を自由に設定（市民・占い師・霊媒師・騎士・人狼・狂人・妖狐）
役職の個別配布（自分のスマホにだけ表示）
夜の行動、昼の投票、勝敗判定
スマホ向けレイアウト
起動方法（Node.jsが必要）
ZIPを展開
展開したフォルダで npm install
npm start
ブラウザで http://localhost:3000 を開く
インターネットで友達と遊ぶには
このアプリをNode.js対応のホスティングサービスにデプロイしてください。デプロイ後に表示されるHTTPSのURLを全員で開きます。サーバーが動作している間、同じルームコードで参加できます。
現時点の試作版の制限
これはオンライン通信に対応したサーバー付きの試作プロジェクトです。ZIPを配っただけではインターネット上に公開されません。ホスティングへのデプロイが必要です。
切断後の再接続・途中参加・ルーム自動削除・荒らし対策は未実装です。
